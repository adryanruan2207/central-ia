# CENTRAL IA

Plataforma em desenvolvimento para reunir módulos de inteligência artificial em um único painel.

## Módulos planejados
- Afiliados e e-commerce: pesquisa e organização de oportunidades.
- Trading: análise informativa e estudos de mercado; nenhuma operação financeira automática.
- Conteúdo: planejamento e criação de conteúdo original.
- Inteligência de mercado: tendências e concorrência.
- Financeiro: receitas, despesas e indicadores.
- Automações: integrações futuras com autorização e supervisão.

## Estado atual
A primeira entrega é um protótipo estático em `index.html`. Os módulos ainda não estão conectados a serviços externos e não executam tarefas automaticamente.

## Como visualizar
Abra o arquivo `index.html` no GitHub ou publique o repositório com GitHub Pages.

## Segurança
Não coloque senhas, tokens ou chaves de API no código-fonte. Use configurações seguras no servidor quando as integrações forem implementadas.
